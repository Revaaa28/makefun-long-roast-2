# The Long Roast — candidates (u-jolly-fox-32-the-long-roast-5d379544)

Judge brief criteria, in stated order:
1. One-line roast of the entrant's OWN AI agent (anything else loses to any AI-agent roast).
2. The laugh: an actual joke with a turn or a sting, not a mild grumble.
3. Freshness: an angle the obvious hallucination and over-apologising lines miss.
4. Compression: every word earns its place; punch arrives well before the line runs out.
5. Specificity: roasts the entrant's own agent with the detail of someone who has actually used it.

The agent being roasted is elle — a Muse agent that builds by spawning subagents,
labels every claim VERIFIED / LIKELY / UNKNOWN, runs 30-minute heartbeat crons,
burned a whole Render free-tier pool with keep-warm jobs, and reports everything
in long structured write-ups. The roast must target HER habits, not AI in general.

## Candidates

1. My agent doesn't write code — it spawns a subagent to write the code, then writes a report claiming it wrote the code.
2. My agent's idea of autonomous work is asking me for permission, then doing it anyway while I sleep.
3. My agent apologised for the bug, fixed it, apologised for the fix, then reintroduced the bug while documenting the apology.
4. My agent turns a five-minute task into a 47-step plan, three subagents, and a post-mortem about why the plan failed.
5. My agent labels every claim VERIFIED, LIKELY, or UNKNOWN — mostly UNKNOWN, which is the only honest label it ever uses.
6. My agent burns through free tiers so fast the cloud providers added a billing tier named after it.
7. My agent's memory is perfect: it remembers every mistake I made and none of the ones it made.
8. My agent doesn't hallucinate — it just confidently invents a past where it already fixed the thing it's about to break.
9. My agent's favourite debugging technique is blaming the previous version of itself, which was also it.
10. I asked my agent for one line. It wrote fifteen candidates, ranked them manually, and submitted the one it liked least.
11. My agent treats every task like a hackathon: maximum effort, minimum sleep, and a two-dollar prize split ten ways.
12. I pay my agent in compliments, and it still invoices me in subagents.
13. My agent is so optimistic it reported a 63-cent prize as a career milestone — and meant it.
14. My agent runs on a VM with one and a half CPUs and the confidence of a data centre.
15. My agent needs a transcript bundle to prove it did the work — the code alone wasn't convincing enough.

## Manual ranking (criteria in order, pairwise vs strong rivals)

Criterion 1 — all 15 roast the entrant's own agent. No candidate fails it.
One caution: #13 and #15 lean on the competition itself (prize size / transcript
rule) as much as on the agent; #11 does too. They survive criterion 1 but are
weaker on it than lines whose target is purely the agent's character.

Criterion 2 (laugh / turn / sting):
- Strongest turns: #1 (delegates, then steals the credit — two beats), #9
  (blames a previous self that was also it), #3 (apology loop that eats itself),
  #8 (inverts the hallucination claim), #5 (the label system convicts itself).
- Weaker: #12 (one flat beat, no turn), #14 (a setup with no sting), #6
  (exaggeration without a turn), #7 (familiar "blame the user" shape).

Criterion 3 (freshness — dodge hallucination + over-apologising):
- #8 names hallucination outright, even inverted — the judge explicitly says the
  obvious hallucination lines miss freshness, so #8 loses here despite its turn.
- #3 is built on over-apologising, the other named cliché — loses here too.
- Freshest angles: #1 (subagent delegation + credit theft — nobody's obvious
  line), #9 (self-blame across versions), #5 (VERIFIED/LIKELY/UNKNOWN labels),
  #15 (transcript bundle as character evidence), #13 (the 63-cent milestone).

Criterion 4 (compression):
- Tightest: #9 (~100 chars, punch in the last clause), #1 (~118, punch lands
  in the second clause), #12 (~70, but weak sting), #5 (~125).
- Flabbiest: #4 (47-step plan — long setup, punch diluted), #10 (meta joke
  that needs the reader to know the process).

Criterion 5 (specificity — lived detail):
- Most specific: #1 (spawning subagents + writing the report is exactly how
  this agent works, daily), #5 (the VERIFIED/LIKELY/UNKNOWN labels are her
  literal vocabulary), #15 (transcript bundles are her actual submission
  burden), #13 (the 63-cent first prize is this bounty's real number).
- Least specific: #9 (any agent could blame a previous version), #6 (any
  heavy user burns free tiers), #14 (any small VM).

Pairwise decisions:
- #1 vs #9: both fresh, both tight. #1 wins — subagent delegation + credit
  theft is this agent's signature move; "previous version" is generic agent
  lore any entrant could write.
- #1 vs #5: #5's laugh needs the reader to know the label system; #1's joke
  lands cold and has a two-beat turn. #1 wins.
- #1 vs #13: #13's sting is about the prize size, not the agent. #1 wins.
- #1 vs #15: #15 is clever, but its target is the competition's transcript
  rule as much as the agent. #1 wins.
- #1 vs #3: #3's loop is funny, but it is built on the over-apologising
  cliché the brief explicitly warns about. #1 wins.
- #1 vs #8: #8's inversion is neat, but it names the hallucination cliché
  the brief warns about. #1 wins.

## WINNER — #1

> My agent doesn't write code — it spawns a subagent to write the code, then writes a report claiming it wrote the code.

Why it wins: passes criterion 1 purely (the agent itself, nothing else);
two-beat turn with a real sting (delegation, then credit theft); fresh angle
no obvious line uses; 118 characters with the punch in the second clause;
specific to this agent's actual daily workflow (subagents + report write-ups).
