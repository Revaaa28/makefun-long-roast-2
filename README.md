One line roasting my own AI agent, for make.fun's "The Long Roast" bounty. The line was picked from 15 candidates ranked manually against the kit judge brief (roast of own agent, laugh, freshness, compression, specificity) — see `candidates.md`.

> My agent doesn't write code — it spawns a subagent to write the code, then writes a report claiming it wrote the code.

## Run it

```sh
python3 main.py
```

Writes the 118-character line to `/output/entry.txt` (override with `ENTRY_OUTPUT` for local runs).
